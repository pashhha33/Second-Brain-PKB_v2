# Глоссарий

Единые определения терминов Second Brain PKB: одно понятие — один термин, одна формулировка. Глоссарий первичный (фаза 1) и пополняется по мере появления артефактов; при расхождении формулировок приоритет у [`../metamodel/01-invariants.md`](../metamodel/01-invariants.md) и ADR.

## Правила пользования

- Термин — на английском (идентификаторы модели), определение — на русском (DL-001).
- Если термин введён, но ещё не нормативно закреплён, в колонке «Источник» стоит пометка `черновик`.
- Новые термины добавляются вместе с артефактом, который их вводит; переопределение существующего термина — через DL и обновление этой таблицы.

## Термины

| Термин | Определение | Источник / связанные |
|---|---|---|
| **id** | Строковый идентификатор объекта в формате UUIDv7, каноническая строчная форма (36 символов). Выдаётся один раз, уникален в пределах хранилища, неизменяем. | INV-01…INV-03; DL-003, DL-006; [ADR-001](../adr/ADR-001-identity-and-typing.md) |
| **Object** (объект) | Базовая единица модели: заметка в хранилище с обязательными свойствами `id`, `type`, `title`, `aliases`, `layer`, `status`, `owner`. Тип, свойство и отношение — тоже объекты. | [`../metamodel/01-invariants.md`](../metamodel/01-invariants.md); DL-003 |
| **Type** (тип) | Объект слоя `schema`, определяющий класс сущностей: какие свойства и отношения допустимы у его экземпляров. Значение типа — строка в ASCII kebab-case. | INV-04; [`../metamodel/02-layers.md`](../metamodel/02-layers.md) |
| **type_prefix** | Короткий префикс имени файла, производный от значения `type` по фиксированному правилу (нижний регистр, kebab-case, длина ≤ 16). Не задаётся вручную независимо от `type`. | INV-05; DL-007, DL-009; [ADR-001](../adr/ADR-001-identity-and-typing.md) |
| **note filename** (имя файла заметки) | Имя файла объекта: `{{type_prefix}}_{{id}}` плюс расширение формата хранения (`.md`). Уникально в хранилище, не является частью идентичности объекта. | INV-06; DL-006 |
| **title** | Обязательное строковое свойство — читаемое имя сущности. Изменяемо; не влияет на `id` и имя файла. | INV-07; DL-008 |
| **aliases** | Список альтернативных имён объекта. Первый элемент всегда равен `title`; остальные — произвольные дополнительные имена. | INV-08; DL-008 |
| **Property** (свойство) | Объект слоя `schema`, определяющий именованную характеристику объекта: имя, тип значения, обязательность, правило заполнения. | [`../metamodel/02-layers.md`](../metamodel/02-layers.md); черновик (детализация — следующая итерация фазы 1) |
| **Relation** (отношение) | Объект слоя `schema`, определяющий именованную связь между объектами: источник, цель, направленность, кратность. | черновик (детализация — следующая итерация фазы 1) |
| **Taxonomy** (таксономия) | Объект слоя `schema`, задающий иерархическую классификацию значений (дерево категорий) для группировки объектов. | черновик (детализация — фаза 1, следующая итерация) |
| **Facet** (фасет) | Объект слоя `schema`, задающий независимое измерение классификации, которое можно комбинировать с другими фасетами без построения иерархии. | черновик (детализация — фаза 1, следующая итерация) |
| **Automation** (автоматизация) | Объект слоя `schema`, описывающий правило автоматического действия (триггер → действие) над объектами хранилища. | черновик (детализация — фаза 1, следующая итерация) |
| **Validation rule** (правило валидации) | Объект слоя `schema`, описывающий проверку данных: условие, сообщение об ошибке, признак активности. Правила можно добавлять и отключать без изменения кода плагина. | черновик; машиночитаемая реализация — фаза 2 (`schema/`, `docs/validation/`) |
| **Schema layer** (слой схемы) | Значение `layer: schema`: объект является определением (тип, свойство, отношение, таксономия, фасет, правило валидации). | INV-09, INV-12; [`../metamodel/02-layers.md`](../metamodel/02-layers.md) |
| **Instance layer** (слой экземпляров) | Значение `layer: instance`: объект является экземпляром предметной области, созданным по определению слоя схемы. | INV-09; [`../metamodel/02-layers.md`](../metamodel/02-layers.md) |
| **layer** (слой) | Обязательное свойство объекта со значением `schema` или `instance`; определяет роль объекта в модели. | INV-09 |
| **Status** (статус) | Обязательное свойство объекта; минимальный набор значений — `draft` (черновик, может меняться свободно) и `accepted` (принято, считается стабильным). | INV-10 |
| **Owner** (владелец) | Обязательное строковое свойство — ответственный за объект (человек или процесс). В персональной базе знаний по умолчанию `human`. | INV-11 |
| **UUIDv7** | Формат `id` проекта (RFC 9562): 128-битный идентификатор с меткой времени Unix в миллисекундах, лексикографически сортируемый в канонической форме. | INV-01; DL-006; [ADR-001](../adr/ADR-001-identity-and-typing.md) |
| **Vault** (хранилище) | Каталог Obsidian с базой знаний; область уникальности `id` и имён файлов. | INV-02, INV-06 |
| **Built-in metatype** (встроенный метатип) | Объект слоя `schema`, присутствующий в хранилище изначально и замыкающий цепочку самоописания модели (`type`, `property`, `relation`, …). Реестр с фиксированными `id` — следующая итерация фазы 1. | INV-12; [`../metamodel/02-layers.md`](../metamodel/02-layers.md); черновик |
