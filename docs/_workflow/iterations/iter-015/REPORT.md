## Подтверждение понимания
1. **«Подмена отображаемого имени в UI по контракту (минимум file explorer; желательно tabs), используя `getDisplayTitle` / `VaultIndex`»** — выполнена как три уровня: решение о подмене осталось в чистом модуле `display-title.ts` (`overrideTitleOf`, `titleErrorNote`) и строится из `VaultIndex` через `createTitleResolver(getEntry, getSettings)`; операции над элементом — в `title-dom.ts`; поверхности — `explorer-title.ts` (проводник) и `leaf-title.ts` (заголовок вкладки и заголовок панели листа); координирует `TitleController`. Публичный API iter-014 (`getDisplayTitle`, `getTitleIndicator`, `hasTitleError`) сохранён без изменений и согласован с решением о подмене (проверка G36).
2. **«Feature-flag в настройках: «Подменять имя на title» (по умолчанию вкл)»** — тумблер в `settings-tab.ts`, значение по умолчанию `override: true` (`DEFAULT_DISPLAY_TITLE_SETTINGS`), состояние в `data.json` плагина в ключе `displayTitle` рядом с видимостью слоёв (§2.1, DL-031); настройки iter-014 без ключа читаются как «включено» (`normalizeSettings` → `normalizeDisplayTitleSettings`), отдельная миграция не нужна. Рядом добавлены строка «Состояние подмены» со счётчиками и кнопка «Обновить».
3. **«Устойчивость к переименованию/изменению frontmatter (события индекса уже есть — подписаться/обновить UI)»** — события хранилища `create`, `modify`, `delete`, `rename` обновляют индекс с iter-014; подмену переприменяют: тот же проход после обновления индекса, новые обработчики `layout-change`, `active-leaf-change`, `file-open`, наблюдатель `MutationObserver` за поддеревом проводника (дебаунс 120 мс) и обёртка `getDisplayText()` экземпляра представления листа — текст вкладки не возвращается к имени файла при перерисовке. Проверено группами H61–H62, I20, I48–I50.
4. **«Минимальный monkey-patch»** — прототипы и глобальные объекты Obsidian не изменяются: текст записывается в элементы интерфейса, обёртка `getDisplayText()` ставится на экземпляре представления и хранит исходную функцию в `Map`, снимается при выключении и при выгрузке. Отклонённые альтернативы (патч `View.prototype.getDisplayText`, переопределение `TFile.basename` / `Vault.getName`, недокументированные свойства `WorkspaceTabs`, `setTooltip`) перечислены в DL-054.
5. **«Не ломать мобильный API без пометки»** — использованы DOM, `MutationObserver` и `setTimeout`, доступные в мобильной webview; `isDesktopOnly: false` в манифесте сохранён. На мобильном устройстве не проверялось — пометка в `plugin/README.md` (раздел «Проверка») и вопрос 8.
6. **«Обновить `plugin/README.md` — как проверить в приложении на `examples/`»** — добавлен раздел «Как проверить в Obsidian на `examples/`» из семи шагов (установка, проводник, вкладки и панель, выключение флага, изменение `title` и переименование, пометка INV-07, команда обновления) с конкретными примерами из набора (`note_01a17d3b-6b10-7d52-9a34-1e7c42b8f056.md` → «Конспект книги How to Take Smart Notes»; `examples/README.md` — файл вне модели, §3.5.1).
