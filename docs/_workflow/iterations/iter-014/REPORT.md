1. **«Минимальный каркас»** выполнен как: `manifest.json`, `package.json`, `tsconfig.json`, `esbuild.config.mjs`, `versions.json`, `README.md` и девять модулей `src/`. 2. **«in-memory индекс (`id`, filename, `type`, `layer`, `title`, path)»**: `VaultIndex` хранит две карты — по `id` и по `path`; запись `IndexEntry` включает требуемые поля (`id`, `basename` как filename, `type`, `layer`, `title`, `path`) и дополнительно `kind`, `frontmatter`, `aliases`, `status`, `owner`, `definedBy`, `typePrefix`, `machineKey`, `expectedLayer`, `missing`, `unsupported`. 3. **«full scan на load + events»**: `onload` → `normalizeSettings(await loadData())` → `rebuildIndex()` по `vault.getMarkdownFiles()` → `registerVaultEvents()` (`create`, `modify`, `delete`, `rename`) → вкладка настроек → команды → лог статистики. `rename` обработан как `index.remove(oldPath)` + `update(file)`: каст `{ path: oldPath } as TAbstractFile` не использовался (некорректен по типам).

Парсер собственный, а не `parseYamlFrontmatter` из API Obsidian: модуль остаётся чистым и проверяемым вне приложения, в бандле нет стороннего кода (основание и риски — DL-051).
