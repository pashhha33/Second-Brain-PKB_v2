## Что сделано

1. **ADR-009 создан** (`docs/adr/ADR-009-phase2-schemas.md`, 157 строк, статус **Accepted**). Контекст — 6 пунктов (состояние фазы 1, отсутствие состава ключей `validation-rule`, неоднородность инвариантов по способу проверки, данные во frontmatter, ограничения итерации, требования фаз 4–5). Решение: **S1** — граница «схема проверяет форму одного объекта, правило проверяет всё, что требует имени файла, другого объекта, множества объектов или вычисления», дублирование схемы правилами запрещено, вычисления (INV-20, INV-26) не проверяются ни тем ни другим; **S2** — экземпляр схемы есть JSON-документ из YAML frontmatter одной заметки, тело и имя файла в него не входят, правила переноса YAML → JSON, `additionalProperties` не запрещён; **S3** — JSON Schema 2020-12, `$id` = относительное имя файла, один файл — один класс объектов, без единого `oneOf` на весь vault, плюс зафиксированные расхождения с принятым текстом (INV-09, `applies_to`, `value_type` у отношений, ключ `required`); **S4** — состав первой волны (три схемы, таблица «файл → класс объектов → что проверяет → инварианты») и осознанно отложенное; **S5** — формат объекта `type: validation-rule` (шесть служебных ключей, `label` / `aliases[1]`, `defined_by`, иллюстративность `id`, неприменение в `draft` / `deprecated`, отказ от регистрации ключей в этой итерации, статус описаний как документации фазы 2); **S6** — что не входит. Альтернативы: **А1** (версия и формат: draft-07, YAML-схемы, собственный формат, `$id` как URN/URL), **А2** (раскладка `schema/`: один файл на модель, файл на каждый вид определения, схемы в `docs/validation/`, две схемы без `media.json`), **А3** (формат правил: таблица без объектов, всё в JSON Schema, исполняемый TypeScript, один файл-реестр, файл на правило), **А4** (шкала `severity`: без `severity`, три уровня, числовая тяжесть), **А5** (что считать экземпляром схемы: frontmatter + имя файла + путь, весь vault, только тело). Последствия — 5 положительных и 6 рисков с компенсациями. Блок «Затрагивает» — 13 путей.
2. **Три схемы JSON Schema 2020-12 созданы** в `schema/`:
