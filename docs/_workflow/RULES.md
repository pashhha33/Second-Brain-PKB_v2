# RULES — накопленные правила проекта

Формат: `R-NNN (iter-NNN, YYYY-MM-DD): правило одной фразой.`
Устаревшие правила не удаляются, а помечаются `[deprecated: iter-NNN]`.

## Правила

R-001 (iter-000, 2026-10-27): Имена файлов — kebab-case. ADR — `ADR-NNN-краткое-имя.md`. Итерации — папки `iter-NNN` внутри `docs/_workflow/iterations/`. ID в тексте — трёхзначные с префиксом (`DL-001`, `ADR-001`, `Q-001`, `R-001`).

R-002 (iter-000, 2026-10-27): Каждый файл в репозитории начинается с H1 (`# Заголовок`) и 1–2 предложений о его назначении.

R-003 (iter-000, 2026-10-27): Ссылки между файлами — относительные (`../decisions/decision-log.md`), не абсолютные URL на GitHub.

R-004 (iter-000, 2026-10-27): Один файл = одна тема. Если файл превышает ~300 строк — кандидат на разбиение, но только через ADR.

R-005 (iter-002, 2026-10-27): Имена `docs/CHECKPOINT.md` и `docs/project-map/PROJECT_MAP.md` — разрешённые исключения из kebab-case (R-001); переименование не выполняется, ссылки используют текущие имена. Основание: принято из разбора вопросов iter-001 (REPORT.md iter-001, вопрос 5), зафиксировано в указаниях TASK.md iter-002.

R-006 (iter-005, 2026-10-27): При достижении файлом ~300 строк файл не растёт — агент останавливается и выносит вопрос о разбиении в REPORT.md (варианты разбиения с оценкой объёма каждого файла), а само разбиение выполняется только через ADR (R-004). Основание: цель 5 TASK.md iter-005; `04-properties-relations.md` достиг 306 строк к концу iter-004 и был разбит только в iter-005 (ADR-005, DL-022).

R-007 (iter-008, 2026-10-28): При добавлении записи в `docs/decisions/decision-log.md` агент в той же итерации обновляет указатели диапазонов DL и перекрёстные ссылки в файлах, которые решение затрагивает (в том числе блоки «Связанные документы», таблицы артефактов и указатели диапазонов правил); такие правки считаются техническими и отдельного пункта в TASK.md не требуют, а их перечень приводится в REPORT.md. Нормативный текст затронутых файлов при этом не меняется. Основание: TASK.md iter-008, п. 4; вопрос 5 REPORT.md iter-007 — указатели в `01-invariants.md` и `02-layers.md` отставали от журнала на три записи (DL-031…DL-033), DL-035.
