# Обложка альбома The Dark Side of the Moon

Обёртка изображения — объект `type: image`, а не сам файл (DL-024, INV-24): обязательный ключ `attachment` хранит путь к вложению строкой, как её записывает Obsidian, форма проверяется схемой [`../schema/media.json`](../schema/media.json) (`$defs/image-wrapper`), наличие ключа — правилом `image-has-attachment`. Существование файла по этому пути моделью не проверяется (INV-24) и остаётся кандидатом правил ([`../docs/validation/00-validation-rules.md`](../docs/validation/00-validation-rules.md), раздел 7).

`creation-method: photograph` — третье значение триггера в наборе после `scan` и `ai-generated` ([`07-core-properties.md`](../docs/metamodel/07-core-properties.md), запись 18): каноническое правило развёртывания определено только для `ai-generated` ([`08-field-expansion.md`](../docs/metamodel/08-field-expansion.md), раздел 6.3), поэтому полей `model`, `prompt`, `seed` у обёртки нет и предупреждение `inactive-field-value` не срабатывает.

Обёртка служит значением свойства `cover` альбома (`media`, INV-23 — правило `media-target-is-image`) и одновременно связана с ним отношением `about`: `source_type` и `target_type` отношения равны `*`, то есть «любой тип слоя `content`» ([`06-relations.md`](../docs/metamodel/06-relations.md), раздел 3, запись 2), — область соблюдена для любого источника и цели из слоя наполнения. В галерею обёртка не входит: ключ `part-of-collection` отсутствует, что допустимо при кратности `0..*` — принадлежность коллекции необязательна даже для изображения ([`05-core-types.md`](../docs/metamodel/05-core-types.md), раздел 4.2).
