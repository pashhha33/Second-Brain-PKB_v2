# Обложка

Определение свойства ядра `cover` — воспроизведение канонического примера [`07-core-properties.md`](../docs/metamodel/07-core-properties.md), раздел 4; `id` реестровый (запись 1 реестра). `value_type: media`: значение — каноническая ссылка на обёртку `type: image` (INV-23), а не путь к файлу и не имя файла.

Область применения — `source`, `album`, `film-series`: свойство действует у потомков `source` без их перечисления (ADR-004, I3), поэтому доступно книге ([`book_01a17d3b-6b21-7d4e-8a1c-2e4f6a8b0c13.md`](book_01a17d3b-6b21-7d4e-8a1c-2e4f6a8b0c13.md)). Форма значения выражена схемой [`core-property-values.json`](../schema/core-property-values.json) (ключ `cover` → `$defs/media-link` схемы [`media.json`](../schema/media.json)); набор значений у `media` отсутствует, а принадлежность цели типу `image` проверяет правило `media-target-is-image`.
