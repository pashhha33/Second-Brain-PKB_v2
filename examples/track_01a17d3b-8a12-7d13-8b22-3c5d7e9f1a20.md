# Time

Экземпляр типа `track` — потомка `source` ([`05-core-types.md`](../docs/metamodel/05-core-types.md), раздел 4, группа «Медиа»): отношения `author`, `about`, `references` и свойства с `applies_to: [source]` унаследованы от предка без повторного объявления (ADR-004, I3). Принадлежность альбому хранится со стороны элемента: `part-of-collection` объявлен для `film`, `track`, `image` и имеет кратность `0..*`, поэтому значение — список YAML канонических ссылок ([`06-relations.md`](../docs/metamodel/06-relations.md), раздел 3, правило 5).

Пара «`track` → `album`» соответствует колонке «Элементы» реестра коллекций (раздел 5): правило `collection-element-consistent` не срабатывает, область определения отношения соблюдена (правило `relation-endpoints-match`), форма значения соответствует кратности (правило `relation-cardinality-form`). Трек может входить и в несколько коллекций — например, в альбом и в сборник, тип которого владелец добавил сам; список из одного элемента формой не запрещён.

`position: 4` — порядок внутри альбома, нумерация с 1, пропуски допустимы ([`07-core-properties.md`](../docs/metamodel/07-core-properties.md), раздел 3, пункт 2); `duration: 7` — длительность в минутах, единица измерения в значении не хранится (раздел 3, пункт 5), а форма `number` схемой двенадцати ключей не ограничена и покрывается `$defs/number-value` точечно (ADR-010, W5). Отношение `author` не указано: его цель — `person` или `organization`, а объекта исполнителя в наборе нет, создавать определение типа `organization` вне задач итерации.
