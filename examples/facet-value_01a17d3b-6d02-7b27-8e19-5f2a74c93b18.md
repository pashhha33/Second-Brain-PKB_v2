# Осмысленное

Значение фасета — объект слоя классификации с обязательным ключом `facet`: одиночная каноническая ссылка на фасет по кратности `1..1`. Форма выражена схемой [`facet-value.json`](../schema/facet-value.json) (DL-043, DL-045); `defined_by` — встроенный метатип `facet-value` (запись 9 реестра).

Привязка знания к значению выполняется отношением `object-facet-value` (кратность `0..*`, значение хранится со стороны объекта слоя наполнения) — пример в [`note_01a17d3b-6b10-7d52-9a34-1e7c42b8f056.md`](note_01a17d3b-6b10-7d52-9a34-1e7c42b8f056.md). Тип цели ключа `facet` (объект `type: facet`) схемой не проверяется: проверку выполняет правило третьей волны `facet-target-is-facet` ([`03-third-wave-rules.md`](../docs/validation/03-third-wave-rules.md), правило 15, iter-013, DL-048).
