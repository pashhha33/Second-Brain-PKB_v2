# How to Take Smart Notes

Экземпляр типа `book` — потомка `source`: свойства `isbn`, `published`, `attachment` и отношения `author`, `artwork` унаследованы от предка без повторного объявления (ADR-004, I3). Книга совмещает две роли из трёх ([`05-core-types.md`](../docs/metamodel/05-core-types.md), раздел 4.1): «карточка + файл» (`attachment`) и «агрегатор глав» — главы связаны отношением `chapter-of` со своей стороны, список глав в книге не хранится.

Значения `cover` и `artwork` воспроизводят пример [`07-core-properties.md`](../docs/metamodel/07-core-properties.md), раздел 2: визуальное свойство ссылается на обёртку изображения, а не на файл (INV-23, INV-24). Значение `about` из примера [`05-core-types.md`](../docs/metamodel/05-core-types.md), раздел 7.1, в набор не перенесено: его цель — объект `concept`, которого в наборе нет.

Свойство-триггер `format` со значением `ebook` разворачивает поля `attachment` и `url` ([`08-field-expansion.md`](../docs/metamodel/08-field-expansion.md), раздел 6.2); оба значения указаны. Самого правила в наборе нет, а оба поля входят в эффективный набор типа по `applies_to` предка `source`, поэтому предупреждение `inactive-field-value` не срабатывает и при неактивном правиле.
