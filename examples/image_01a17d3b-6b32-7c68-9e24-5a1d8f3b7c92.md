# Скриншот графа заметок

Обёртка изображения с минимальным составом полей: восемь универсальных обязательных свойств и `attachment` (INV-24). Ключ `creation-method` не указан — ни одно значение его `enum_values` (`ai-generated`, `photograph`, `scan`, `illustration`) не описывает снимок экрана, а отсутствие ключа и есть пустое значение свойства `required: conditional` ([`04-properties.md`](../docs/metamodel/04-properties.md), раздел 2, правило 2).

Второй элемент галереи (`part-of-collection`, `position: 2`) и второй элемент `artwork` книги — воспроизведение примера [`07-core-properties.md`](../docs/metamodel/07-core-properties.md), раздел 2.
