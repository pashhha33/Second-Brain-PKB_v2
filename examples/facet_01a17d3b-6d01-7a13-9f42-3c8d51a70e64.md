# Статус проработки

Фасет — измерение классификации слоя `classification` ([`02-layers.md`](../docs/metamodel/02-layers.md)); `defined_by` — встроенный метатип `facet` (запись 8 реестра). Значения фасета — отдельные объекты, а не строковое перечисление в самом фасете ([`04-properties.md`](../docs/metamodel/04-properties.md), раздел 6): значение набора — [`facet-value_01a17d3b-6d02-7b27-8e19-5f2a74c93b18.md`](facet-value_01a17d3b-6d02-7b27-8e19-5f2a74c93b18.md).

Состав ключей объекта `type: facet` отдельной схемой не описан (DL-045, отклонённая альтернатива «общий файл `classification.json`»), поэтому форма фасета проверяется только схемой [`object.json`](../schema/object.json).
