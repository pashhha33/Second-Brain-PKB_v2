# Обложка книги How to Take Smart Notes

Обёртка изображения — объект `type: image`, а не сам файл (DL-024, INV-24): обязательный ключ `attachment` хранит строку, как её записывает Obsidian. Форма обёртки проверяется схемой [`media.json`](../schema/media.json) (`$defs/image-wrapper`), наличие ключа — правилом `image-has-attachment`.

`creation-method: scan` — значение свойства-триггера (запись 18 [`07-core-properties.md`](../docs/metamodel/07-core-properties.md)); канонических правил развёртывания для `scan` нет, поэтому дополнительных полей у обёртки не появляется. Обложка одновременно служит значением свойства `cover` книги: переиспользование одной обёртки несколькими объектами допустимо ([`07-core-properties.md`](../docs/metamodel/07-core-properties.md), раздел 2, пункт 3).
