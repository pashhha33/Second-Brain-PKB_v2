# Second Brain PKB

Метамодель персональной базы знаний и плагин для Obsidian, который её поддерживает.

- **Что это:** самоопределяющаяся объектная модель. Тип, свойство, отношение, таксономия, фасет и автоматизация — тоже объекты со своими `id` и `type`. Модель расширяется без изменения кода плагина.
- **Зачем:** личная база знаний, в которой структура не задана заранее жёстко, а описывается той же базой.
- **Как устроен проект:** см. `docs/PROJECT_BRIEF.md`.
- **Как идёт работа:** см. `docs/_workflow/HANDOFF_PROTOCOL.md`.
- **Текущее состояние:** см. `docs/CHECKPOINT.md`.

Документация — на русском. Код, схемы и идентификаторы — на английском.
